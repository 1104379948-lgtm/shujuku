# 飞行模式

飞行模式是**会话级**功能：状态按当前聊天的 `isolationKey` 分槽保存，切换到其他标签不会继承启用状态或隐藏行；新会话及旧版无分槽状态默认关闭，不修改全局默认模板或全局剧情开关。

## 启用与隐藏语义

- 启用前按当前未隐藏的「纪要表」行计数；超过 15 行会被拒绝。
- 启用通过正式模板协调提交完成：纪要表导出改为常量条目并关闭附加索引，同时新增「大总结」表。
- 大总结新增一行时，系统以该次提交后的纪要快照为准，将全部当时可见纪要的 `row_id` 标记为隐藏；同批新增纪要也会被包含。
- 隐藏是运行时投影，不删除或改写物理纪要数据。世界书、自定义填表 prompt 和 `<if cell="...">` 条件看不到隐藏行；SQL/ORM 模板变量仍能读取物理行。

## 停用与不可逆操作

停用会通过正式协调提交恢复启用前模板、清空隐藏行，并跨全部历史**永久删除「大总结」表及其内容**。这是不可逆操作，UI 会要求明确确认。

若启用后用户修改过当前会话模板，停用默认拒绝静默覆盖。需要再次确认后才会按启用前归档模板恢复，并执行大总结硬删除。

## 保全边界与已知限制

- checkpoint、V2 replay、导入导出不会应用隐藏投影，因此物理纪要行保持完整。
- 切换聊天沿用既有约 1.2 秒加载窗口；该窗口内世界书形态可能暂时仍显示上一会话状态。
- 自动合并已废弃，飞行模式不与其交互。
